# Derivative rules

Create optimized WebP/AVIF/JPEG only when tooling is reliable and quality is verified.

Preserve:
- originals;
- aspect ratios;
- documentary integrity.

Record in `public/assets/SOURCE_MANIFEST.md`:
- derivative filename;
- original source;
- PDF page number where applicable;
- caption;
- purpose.

Do not use OCR text from the PDF if it is visibly corrupted.
For visible copy, use manually verified/source text from the rendered pages or DOCX.
